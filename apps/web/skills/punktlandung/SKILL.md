# Punktlandung

Punktlandung tracks the user's Noten at a Gymnasium in Baden-Württemberg. `punktlandung <command>` runs on the Punktlandung server over SSH and only reads; Noten are entered and changed in the app. Run `punktlandung --help` for commands and `punktlandung <command> --help` for options. Output is JSON on stdout. Errors are JSON on stderr, `{"error":{"tag","message"}}`, and exit 1, or 2 for invalid arguments (`UsageError`, `InvalidInput`). `DatabaseUnavailable` means the database couldn't be read and `DoorUnavailable` that the server or a live release couldn't be reached. Other tags come from Punktlandung itself, with German messages.

- `punktlandung halbjahre list` returns `{defaultHalbjahrId, halbjahre: [{id, label, klassenstufe, schoolYear, half, system, startsOn, endsOn, notenCount}]}`, latest first. The other commands read the default Halbjahr, the current one or else the last one begun, unless `--halbjahr` names another by id or by label such as `10.2` or `J1.1`. A label that occurs in two school years, after a repeated Klassenstufe, needs the id.
- `system` is `sechser` (1 to 6, lower is better) or `punkte` (Notenpunkte 0 to 15, higher is better, in J1 and J2). A Halbjahr never mixes them, so never average or compare values across systems.
- `punktlandung noten list` returns `{halbjahr, faecher: [{id, name, shortName, archived, gewichtung}], noten}`, each Leistung being `{id, kind, gewicht, datum, notiz, preparation, fachId, fachName, fachKuerzel, status}` plus `wert` when `status` is `graded`. A `planned` Leistung is an announced Klausur, Test or GFS on `datum` without a Note yet and counts in no average. `preparation` is the user's Markdown study plan for it.
- `kind` is `klausur`, `test` or `gfs` (Wertungsbereich schriftlich) or `muendlich` or `sonstige` (mündlich). A Fach's `gewichtung` is `{verhaeltnis, arten}`. With `verhaeltnis` null, all of the Fach's Noten form one weighted list; otherwise each Wertungsbereich is averaged on its own and the two are combined in the ratio `{schriftlich, muendlich}`, and a Bereich without Noten drops out. `arten.<kind>` is `{gewicht, sammlung}`: `einzeln` counts each Note with weight `gewicht` times the Leistung's own `gewicht`; `gesammelt` first averages the kind's Noten, weighted by their own `gewicht`, into one Note of weight `gewicht`.
- `punktlandung zeugnis` returns `{termId, label, schoolYear, system, gesamtschnitt, zeilen: [{fachId, fachName, archived, anzeige, anzahlNoten}], jahresvorschau}`. `anzeige` is the Fach's Halbjahresnote as the app shows it: quarter steps in `sechser` (`2-` is 2.25, `2-3` is 2.5, `3+` is 2.75), whole points in `punkte`, null without Noten. `gesamtschnitt` averages those rounded notes, formatted like `2,25` or `11 P.`. `jahresvorschau` is null until a `sechser` school year has both Halbjahre; then it lists each Fach's whole Jahresnote over the year, and `grenzfall` marks an average near ,5 that the teacher may round either way.
- Quote averages from `zeugnis` rather than computing them yourself. Use the Gewichtung only for what the app doesn't show, such as which Note a coming Klausur would need.
